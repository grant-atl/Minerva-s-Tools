# Ponytail complexity audit

Read-only audit, 2026-09-23. Traced static and dynamic imports from `src/main.tsx`, then checked every proposed deletion with repository-wide `rg`, including tests and configuration. Counts are estimated source lines and direct dependency declarations; lockfile/generated files and the already removed Windows 98 feature are excluded. No changes below were applied by this audit.

- delete: Remove 32 unreachable UI modules and both unused `use-mobile` copies: **4,432 lines, 8 dependencies**. Replacement: nothing. The UI files are `alert-dialog`, `alert`, `aspect-ratio`, `avatar`, `breadcrumb`, `calendar`, `card`, `carousel`, `chart`, `checkbox`, `collapsible`, `command`, `context-menu`, `dialog`, `drawer`, `form`, `hover-card`, `input-group`, `input-otp`, `menubar`, `navigation-menu`, `pagination`, `popover`, `progress`, `radio-group`, `resizable`, `scroll-area`, `separator`, `sidebar`, `skeleton`, `toggle-group`, and `toggle` (all `.tsx`). Only internal dead-module references remain: `sidebar` → `use-mobile`/`separator`/`skeleton`, `command` → `dialog`/`input-group`, and `toggle-group` → `toggle`; every other module has zero callers. Remove `cmdk`, `embla-carousel-react`, `input-otp`, `react-day-picker`, `react-hook-form`, `react-resizable-panels`, `recharts`, and `vaul` after those files. [Largest module](<../src/components/ui/sidebar.tsx#L1>), [form dependency](<../src/components/ui/form.tsx#L4>), [duplicate hook](<../src/hooks/use-mobile.tsx#L1>).
- shrink: Consolidate the second toast implementation into the already used Sonner API: **329 lines, 2 dependencies**. Convert the four real callers in `ShareToolButton`, `FontPairing`, `TypographyScale`, and `FaviconGenerator`, preserving error severity and descriptions; remove the extra App toaster, `hooks/use-toast.ts`, `ui/toast.tsx`, `ui/toaster.tsx`, and unused `ui/use-toast.ts`. Replacement: `toast.success(...)` / `toast.error(...)` from `sonner`; then remove `lucide-react` and `@radix-ui/react-toast`. [Legacy state machine](<../src/hooks/use-toast.ts#L5>), [two mounted toasters](<../src/App.tsx#L209>), [real shared caller](<../src/components/ShareToolButton.tsx#L19>).
- delete: Remove the orphan `HeroHeadline` and its sole dependency `gsap`: **114 lines, 1 dependency**. Replacement: nothing; the current home page supplies its own heading and there are no `HeroHeadline` imports anywhere. [Unused component](<../src/components/HeroHeadline.tsx#L1>).
- delete: Remove unused `NavLink.tsx`, comment-only `App.css`, and the `expect(true).toBe(true)` example test: **36 lines**. Replacement: nothing; `NavLink` and `App.css` have zero references, and the example checks no product behavior. The unused `src/assets/landing/tools-showcase.jpg` can also be removed (39,870 bytes, excluded from line totals). [Unused compatibility wrapper](<../src/components/NavLink.tsx#L5>), [empty stylesheet](<../src/App.css#L1>), [placeholder test](<../src/test/example.test.ts#L3>).
- native: Remove `terserCache`, `cssoCache`, `loadTerser`, and `loadCsso`: **16 lines**. Replacement: `const terser = await import("terser")` and `const csso = await import("csso")` at their two actual callers; JavaScript already caches imported modules. Keep the HTML WASM initialization cache, which protects an actual initialization operation. [Redundant caches](<../src/lib/code-transformers.ts#L14>), [delegating loaders](<../src/lib/code-transformers.ts#L47>), [real callers](<../src/lib/code-transformers.ts#L110>).
- yagni: Remove the unconsumed accessibility context and its memoized value: **11 lines**. Replacement: a fragment around `children` and `AccessibilityMenu`, retaining existing state, persistence, keyboard behavior, and direct menu props. `AccessibilityContext` is private to this file and there is no context consumer. [Context](<../src/components/AccessibilityProvider.tsx#L54>), [unused value](<../src/components/AccessibilityProvider.tsx#L461>).
- delete: Remove unreferenced `hslToHex`, `decimalToRatio`, and `tailwindColors` exports: **10 lines**. Replacement: nothing; repository-wide symbol searches return only their declarations. Keep `hslToRgb`, `rgbToHex`, `simplifyRatio`, and `allColors`, which have real callers. [hslToHex](<../src/lib/color-utils.ts#L79>), [decimalToRatio](<../src/lib/aspect-ratio.ts#L61>), [tailwindColors](<../src/lib/tailwind-colors.ts#L49>).

[Wrapper](<../src/components/MegaNav.tsx#L1>), [caller](<../src/pages/tools/LoremIpsumGenerator.tsx#L6>).
- delete: Remove the unused React Query client/provider: **4 lines, 1 dependency**. Replacement: leave the existing child providers in place; no query/mutation hook, client access, or query-cache consumer exists anywhere. Remove `@tanstack/react-query` and its two Vite dedupe entries. [Import](<../src/App.tsx#L1>), [unused client](<../src/App.tsx#L203>), [dedupe](<../vite.config.ts#L19>).

Keep the Sonner wrapper itself: its icon and styling configuration is used. [Only theme consumer](<../src/components/ui/sonner.tsx#L3>).
- delete: Remove the remaining **29 unused direct dependency declarations**: `@hookform/resolvers`, `date-fns`, `zod`, and the 26 `@radix-ui/react-*` entries other than `react-toast`. Replacement: retain the `radix-ui` package already imported by current controls. Two entries (`react-label`, `react-slot`) depend on removing the dead `form.tsx` above; the other 24 have no source/config imports now. This reduces manifest maintenance; Radix internals may remain transitively installed, so 26 fewer declarations does not mean 26 packages disappear from the bundle. `react-toast` is counted only in the toast migration above. [Manifest](<../package.json#L18>), [current Radix imports](<../src/components/ui/button.tsx#L3>).

Retain the UUID fallback unless browser support is deliberately narrowed; retain the Figtree dependency while the typography tool offers that font; retain the Shadcn CLI/config as an intentional component-development workflow. Correctness, security, and performance findings belong to the separate site review and are not included in this complexity total.
